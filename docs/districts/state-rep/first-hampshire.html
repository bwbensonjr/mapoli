Massachusetts First Hampshire State Representative District

This Massachusetts State Representative district, known as the First Hampshire District, includes Northampton and surrounding towns. The current incumbent is Lindsay N. Sabadosa (D-Northampton), who has represented the district since winning election in 2018 and has run unopposed in all her elections.
