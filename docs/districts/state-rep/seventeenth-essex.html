Massachusetts Seventeenth Essex State Representative District

The 17th Essex State Representative District in Massachusetts includes parts of Andover and Lawrence. It has been represented by incumbent Democratic Representative Frank A. Moran of Lawrence since 2012, who has run unopposed in the last several elections.
